Tips for colors & styles

Tired of the static, grey taskbar? Transparent Taskbar+ Lite brings professional aesthetic tools to your Windows desktop. Whether you want a minimalist transparent look or a vibrant animated gradient, our engine delivers it with zero impact on system stability.

Color Selection - Visuals

Colors in Styles

To change the color for a style, click on it and either:

  • slide the bar to the desired color
  • slide the pointer to match the exact color

or:

  • Choose directly the R, G and B color you want.

When you have choose the color you want, click on Apply button

Double Gradient

Gradient 50-50 style

When you select the two colors split gradient, choose the one as a slightly darker of the same color. For example:

  • green light with green dark,
  • blue light with blue dark,
  • etc.

The right color is the lower one as seen in the gradient. The left one appears on the top of the gradient.

This style mimics the old Windows Vista taskbar style (!)

Minimize Memory Usage

Let TTB+ on background only

The Transparent Taskbar+ Lite will autostart with the Windows start. To minimize any memory usage, just keep the Settings User Interface closed, either it is the Browser UI or the Windows UI.

Effects & Performance

GPU Powered

When using one of the available effects, keep in mind that the app will make use of a very small percentage of the GPU when needed, when the mouse is over the Taskbar. If you don't enable effects, no gpu is used.

General Tips & Suggestions:

  • App Hangs: If the app is ever hangs or stalled, you can simply press the "Reset Taskbar" button on the Settings User Interface or the "Reload Taskbars" option on the Action Center Menu. This will restart the Transparent Taskbar+ and restore the Taskbar to the desired style!
  • Styles: Prefer dark colors for background overlays, color buttons, macOS-Dock color, simple gradient
  • Interactive Video Effects: When you use the Transparent Line or the Transparent (clean) style, it is advised to use a highlight effect.
  • Exit the App: If you want to exit the app and restore the Taskbar to its default setting, just do it from the actions menu (Action center): Button: "Close the App"
  • Registry-Safe: We never touch your Windows Registry, keeping your OS clean and fast.
  • No disturb: Runs quietly in the background. Quick access via Windows system tray
  • Use Desktop Live Wallpaper+ for full experience (free also from the Microsoft Store)
  • Use the Browser UI: faster loading and less memory consumption
  • On Windows Startup if you don’t want to load the UI just uncheck the option (!)
  • If you don’t want GPU then disable the video effects completely.
  • To apply a new style just click the Apply button. The app will remember your preferences.

Frequently Asked Questions

Does the app slow down Windows?

No. Transparent Taskbar+ Lite runs in the background and uses minimal system resources.

Do I need internet for the browser interface?

Yes. The browser interface requires an internet connection.

Can I exit the app?

Yes. Open the system tray menu and select Exit to stop the application completely.
