How to Use Transparent Taskbar+ Lite

Step 1: Install the App

Download and install Transparent Taskbar+ Lite from the Microsoft Store. The application will run in the background automatically.

Step 2: Open the Settings Interface

Click the Transparent Taskbar+ icon in the Windows taskbar system tray (Action Center). The action menu appears:

Choose either:

  • Browser UI: opens in your web browser, uses less memory, requires internet connection.
  • Windows UI: classic desktop window, works offline, slightly higher memory usage.

Step 3: Customize App Appearance

You can easily switch and and select your preferred theme (dark or light) from the User Interface.

The app supports two different themes: Dark and Light:

Step 4: Apply and Enjoy

Your Windows taskbar is now transparent or stylized, running in the background while you continue using your system normally.

If you apply the "Button Glass" style, your Windows taskbar is now full transparent but every app icon has a dynamic glass layer below the icon.

Transparent Taskbar+ Lite vs TranslucentTB

Transparent Taskbar+ Lite is a lightweight alternative to TranslucentTB. Unlike TranslucentTB, it offers both a browser interface for minimal memory usage and a Windows interface for offline configuration. Ideal for users who want flexibility and simplicity.

It is completely free, without hidden features or time limitation.
